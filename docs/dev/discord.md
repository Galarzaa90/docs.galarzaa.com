# :fontawesome-brands-discord: Discord

## Message Limits

| Type              | Length               |
| ----------------- | -------------------- |
| Content           | 4000 characters [^1] |
| Embed Title       | 256 characters       |
| Embed Description | 4096 characters      |
| Fields            | 25 field objects     |
| Field Name        | 256 characteers      |
| Field Value       | 1024 characters      |
| Footer Text       | 2048 characters      |
| Author Name       | 256 characters       |
| Embed Count       | 10 embed objects     |
| Embed Total       | 6000 characters [^2] |
| Components        | 40 components        |
| Components Text   | 4000 characters      |


[^1]: Only applies to Nitro users and bots. Regular users have a 1,000 character limit.
[^2]: The combined sum of all characters in the title, description, field names, field values, footer text and author name.
